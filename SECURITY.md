# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Shifting Front is a client-side browser application that operates deterministically without external backend databases or account credentials.

If you identify a security or privacy issue (such as an insecure dependency, improper sandbox escape, or unintended data exposure), please report it responsibly:

1. Open a private security advisory on GitHub: [Report Security Advisory](https://github.com/zakaihamilton/shiftingfront/security/advisories/new)
2. Or contact the maintainer directly via GitHub issues.

Please provide:

- A clear description of the issue.
- Reproduction steps or proof-of-concept code.
- Details regarding potential impact.

We strive to acknowledge and address all reports promptly.
